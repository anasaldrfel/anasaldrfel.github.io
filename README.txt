قياسات المرمر: النسخة المستقلة (تعمل بدون إنترنت)

محتويات المجلد (ارفعها كلها كما هي، ولا تغيّر أسماءها):
  index.html            التطبيق نفسه
  manifest.webmanifest  بيانات التطبيق (الاسم والأيقونة)
  sw.js                 يحفظ التطبيق على الجوال ليعمل بدون إنترنت
  icon-*.png, apple-touch-icon.png   الأيقونات
  .nojekyll             ملف فارغ مطلوب لاستضافة GitHub Pages

الخطوة 1: رفع الملفات على استضافة مجانية (GitHub Pages)
  1. أنشئ حساباً على github.com (مجاني).
  2. من زر + أعلى الصفحة اختر New repository.
  3. الاسم: اكتب اسم_المستخدم.github.io  (مثال: ahmad.github.io) واجعله Public، ثم Create.
     ملاحظة: بهذا الاسم يكون رابط التطبيق https://اسم_المستخدم.github.io/ مباشرة، وهذا مطلوب لإخفاء شريط العنوان في الـAPK.
  4. داخل المستودع اضغط Add file ثم Upload files، واسحب كل ملفات هذا المجلد (فك الضغط أولاً)، ثم Commit changes.
     إذا لم يظهر الملف .nojekyll على الجوال أنشئه من Add file > Create new file بالاسم .nojekyll وأبقه فارغاً.
  5. افتح Settings ثم Pages. تحت Source اختر Deploy from a branch، الفرع main والمجلد / (root)، ثم Save.
  6. بعد دقيقة إلى دقيقتين يصبح التطبيق على https://اسم_المستخدم.github.io/

الخطوة 2: التجربة والتثبيت كتطبيق (بدون APK)
  1. افتح الرابط في Chrome على الجوال وانتظر حتى يكتمل تحميل الصفحة.
  2. من قائمة ⋮ اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
  3. اختبر: شغّل وضع الطيران وافتح التطبيق من الأيقونة. يجب أن يعمل كاملاً.

الخطوة 3: تحويله إلى APK
  1. من متصفح الكمبيوتر أو الجوال افتح pwabuilder.com.
  2. الصق رابط التطبيق واضغط Start. انتظر انتهاء الفحص.
  3. اضغط Package for stores ثم Android ثم Generate Package.
  4. في الخيارات: Package ID مثل com.elora.qiyasat، واسم التطبيق: قياسات المرمر.
     في خانة Signing key اختر New ليولّد مفتاحاً جديداً.
  5. حمّل الملف المضغوط الناتج. فيه ملف .apk للتثبيت على الجوال، وملف مفتاح التوقيع مع كلمات السر.
     احتفظ بالمفتاح وكلمات السر في مكان آمن، فبدونها لا تستطيع تحديث التطبيق لاحقاً.
  6. انقل ملف الـAPK إلى الجوال وافتحه. اسمح بتثبيت التطبيقات من مصادر غير معروفة عند الطلب.

الخطوة 4: إخفاء شريط العنوان في الـAPK (اختيارية)
  داخل الملف المضغوط من PWABuilder ملف اسمه assetlinks.json.
  1. في مستودع GitHub أنشئ ملفاً بالمسار .well-known/assetlinks.json والصق فيه محتوى الملف.
  2. بعد دقيقة افتح https://اسم_المستخدم.github.io/.well-known/assetlinks.json وتأكد أنه يظهر.
  بدون هذه الخطوة يعمل التطبيق، لكن يظهر شريط عنوان صغير أعلى الشاشة.

ملاحظات
  - افتح التطبيق مرة واحدة مع الإنترنت بعد التثبيت، ثم يعمل بدون إنترنت.
  - القياسات المحفوظة تُخزَّن على الجوال داخل Chrome. مسح بيانات Chrome يحذفها، فصدّر الـPDF لكل قياس.
  - زر «مشاركة» يفتح قائمة الجوال ليرسل الملف عبر الواتساب. زر «حفظ PDF» يحفظه في التنزيلات.
  - الخطوط (El Messiri و IBM Plex Sans Arabic) تُحمَّل من الإنترنت في أول فتح ثم تُحفظ على الجوال وتعمل بدونه.
  - يحتاج الـAPK أن يكون متصفح Chrome مثبتاً على الجوال.
  - لتحديث التطبيق لاحقاً: غيّر رقم النسخة في sw.js (مثلاً من qiyasat-v5 إلى qiyasat-v6) وارفع الملفات من جديد.
